# คู่มือการใช้งาน Trade Buddy War Room

## ข้อมูลตลาด

แอพใช้ Binance Public API สำหรับดึงข้อมูลคริปโต ไม่ต้องใช้ API Key และไม่เชื่อมต่อบัญชีเทรดจริง

รองรับ custom watchlist สำหรับคู่ USDT บน Binance เช่น BTCUSDT, ETHUSDT, SOLUSDT, BNBUSDT, XRPUSDT, DOGEUSDT, ADAUSDT, LINKUSDT, AVAXUSDT และ SUIUSDT

## วิธีเพิ่มเหรียญ

1. ไปที่หน้า สแกน
2. พิมพ์ Symbol เช่น `BTCUSDT` หรือ `BTC/USDT`
3. ระบบจะแปลงเป็นตัวพิมพ์ใหญ่และตรวจสอบกับ Binance Public API
4. ถ้าพบ Symbol ระบบจะบันทึกเข้า watchlist ใน localStorage

## กราฟ

การ์ด Scanner แสดง mini price chart จาก candle สาธารณะของ Binance เพื่อช่วยดูภาพรวมราคาแบบเร็ว ๆ กราฟนี้เป็นตัวช่วยวางแผน ไม่ใช่สัญญาณให้เข้าเทรดทันที

## ความปลอดภัย

ข้อมูลตลาดอาจมีดีเลย์หรือผิดพลาดได้ ควรตรวจสอบจากแอพเทรดจริงก่อนตัดสินใจ

แอพไม่มี auto trading, ไม่เชื่อมต่อบัญชี exchange, ไม่ขอ Binance API key และไม่ใช้ OpenAI API
